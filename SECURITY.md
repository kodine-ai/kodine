# Security

If you believe you have found a security vulnerability in Kodine, please
report it privately:

- **Email:** destek@kodine.net (subject: "Security")
- Include: affected version, steps to reproduce, and potential impact.

We aim to acknowledge reports within 2 business days and will keep you
updated as we investigate and fix the issue.

Please do not open public GitHub issues for security reports, and do not
test vulnerabilities against other users' accounts or data.
